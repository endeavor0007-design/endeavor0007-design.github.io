申し込みの準備状況を見る

こんな不安はありませんか

夜、AI でサイトを作り終えたあとに浮かびやすい心配です。

  • 鍵が見えていないかサービスをつなぐ秘密の鍵が、誰でも読める場所に入っていないか。
  • 管理画面が開いていないかログインなしで管理用のページが見えていないか。
  • 個人情報が載っていないかメールアドレスや電話番号を、意図せず載せていないか。

流れは3つだけ

他人のサイトは点検できない作りです。

  1. URL とメールを入れる受付を始めたら、このページの入力欄から申し込みます。確認コードが届きます（72時間有効）。
  2. 確認用の1行を足す
    ご自身のサイトだと確かめるため、届いたコードをサイトに足します。自分で書かなくても、AI にこの文を貼るだけで済みます。
    私のサイトの本人確認のため、トップページの、画面に出ない設定の部分（head と呼ばれる所）に <meta name="aftercare-verify" content="（届いたコード）"> を1行足して。足したあと、公開し直す手順も教えて。
    ノーコードの作成サービスなどで足し方が分からないときは、使っているサービスの名前を info@cocreturn.com へお知らせください。足し方をお返事します。
  3. 結果を受け取る12項目の有無と、13番目（公開の API の応答）の要確認の印を見て、「場所・根拠・なぜ困るか・直し方・AI に貼る文」の5点で返します。直したあとは同じ入口からもう一度見られます。

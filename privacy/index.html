プライバシーポリシー

YouTube チャンネルの管理での情報の扱い／制定 2026年10月29日

共創還元（COCRETURN・個人事業。以下「当事業」）は、当事業が運営する YouTube チャンネルを管理するために、自作の管理ツール（以下「本ツール」）で YouTube API サービスを使います。本ツールで扱う情報を、次のとおり定めます。なお、各サービス（ワケッコ・まんが化工房など）の利用者の情報の扱いは、それぞれのサービスのプライバシーポリシーによります。

1. 本ツールを使う人

本ツールは当事業だけが使う内部の道具で、一般の方に提供するものではありません。本ツールが Google アカウントへのアクセスを求めるのは、当事業自身のアカウントと、そのアカウントで管理する当事業のチャンネルだけです。

2. YouTube API サービスを通じて取得する情報

  • 当事業のチャンネルの情報（チャンネル名・登録者数など）
  • 当事業が公開した動画の情報と、再生回数・視聴時間などの統計
  • 当事業の動画に寄せられたコメント（コメントした方の表示名と、公開されているコメントの本文）

3. 利用目的

  • 当事業のチャンネルの運営（動画の改善、コメントへの返信、迷惑なコメントの非表示や報告）
  • どの動画がよく見られたかを集計し、次の動画づくりに生かすこと

これ以外の目的には使いません。広告の配信やほかの事業への流用、第三者への販売はしません。

4. 保管と削除

  • 取得した情報とアクセスのための鍵は、当事業の管理する端末に保存し、第三者に渡しません。
  • 統計は、動画の改善のための集計に使います。
  • 現在、コメントの写しは保存していません。今後保存する場合は、返信と改善の検討のためだけに使い、取得から90日以内に削除します。
  • YouTube 上のコメントそのものの削除・編集は、コメントした方ご本人が YouTube で行えます。
  • 本ツールへのアクセスの許可を取り消したときは、手元に保存した情報を速やかに削除します。

4-2. 開示・訂正・削除などのご請求

当事業が保有するご自身の情報について、開示・訂正・利用停止・削除のご請求は、下の連絡先のメールでお受けします。ご本人であることを確かめたうえで、合理的な期間内（原則として2週間以内）に対応します。

5. 第三者への提供

法令に基づく場合を除き、取得した情報を第三者に提供しません。

6. Google と YouTube のポリシー

本ツールは YouTube API サービスを使っています。YouTube の利用には YouTube 利用規約 が適用され、Google による情報の扱いは Google プライバシー ポリシー によります。

本ツールへのアクセスの許可は、Google アカウントのセキュリティ設定（サードパーティのアクセス）からいつでも取り消せます。

本ツールが Google API から受け取った情報の利用と他のアプリへの転送は、Google API Services User Data Policy（限定的使用の要件を含む）に従います。
